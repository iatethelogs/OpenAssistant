# OpenAssistant

Открытый проект автономной умной колонки. Все функции разрабатываются для работы на собственном оборудовании, без облачной обработки. Цель - получить полную независимость умного дома от облачных сервисов.

## Software

- [WakeForge](software/wakeforge/README.md) — создание датасетов, обучение и экспорт моделей слова активации в TFLite.

## Hardware

[Аппаратная часть](hardware/README.md) — используемые платы, аудиотракт и распиновка.
