# OpenAssistant

**Полностью открытый проект умной колонки, которая работает без интернета и облачных сервисов.**

Мы создаём голосового ассистента, которому не нужны подписки, чужие серверы или постоянное подключение к сети. Распознавание речи, обработка команд, генерация ответов и синтез голоса должны выполняться локально, на собственном оборудовании.

Проект состоит из отдельных компонентов, которые можно использовать как вместе, так и самостоятельно. Исходный код открыт, чтобы каждый мог собрать свою колонку, адаптировать её под собственное оборудование и участвовать в разработке.

## WakeForge

[**WakeForge**](wakeforge/README.md) — инструмент для создания собственных моделей слова активации. Он помогает подготовить голосовой датасет, обучить нейросеть и получить компактную модель для ESP32 и других устройств.

Другие части голосового ассистента будут появляться в репозитории по мере разработки.
