# OpenAssistant

OpenAssistant — программная платформа голосового ассистента, которую можно запустить на собственном сервере и использовать с колонкой или компьютером. Сервер отвечает за распознавание речи, диалог, синтез голоса, музыку и управление подключёнными устройствами.

Проект не привязан к одному корпусу, названию колонки или языковой модели. «Мартин» — название одного из разрабатываемых вариантов колонки и её слова активации, а не имя всей системы.

## Что уже работает

**Голос и диалог.** OpenAssistant принимает речь с подключённого клиента, распознаёт её через GigaAM, передаёт запрос языковой модели и озвучивает ответ через Qwen3-TTS. Можно использовать готовые голоса или создавать голос по описанию с помощью VoiceDesign. В настройках синтеза доступны режимы повторяемой генерации и параметры произношения. Текстовый диалог также доступен в браузере.

**Выбор моделей.** Сервер работает с локальными GGUF-моделями через llama.cpp. В мастере можно выбрать модель, скачать её, настроить запуск на CPU или GPU и проверить результат. Распознавание и синтез речи настраиваются отдельно. Уже скачанные модели и их кеши отображаются в интерфейсе.

**Память разговоров.** Диалоги сохраняются между подключениями и перезапусками. Для разных собеседников можно выбрать отдельные профили: ассистент использует недавние реплики и подходящие фрагменты предыдущих разговоров. Профиль выбирается вручную, автоматического определения человека по голосу пока нет.

**Home Assistant.** Подключение по адресу сервера и долгоживущему токену. Доступны получение списка устройств, чтение их текущих состояний и разрешённые команды управления освещением, выключателями, вентиляторами, шторами и медиаплеерами. Управление включается отдельно. После команды сервер запрашивает состояние повторно и не сообщает об успешном выполнении, если не получил подтверждения. Поддержка устройств и формулировок запросов пока ограничена.

**Музыка и радио.** Подключение собственного аккаунта Яндекс Музыки, поиск треков и воспроизведение через совместимый клиент. Для интернет-радио доступен поиск станций через Radio Browser. Возможность воспроизведения конкретного трека зависит от сервиса, аккаунта и поддерживаемого формата потока.

**Управление.** Веб-интерфейс показывает состояние сервисов и видеокарт, позволяет устанавливать модели, проверять микрофон и синтез, менять голос, подключать внешние сервисы и просматривать журналы. Действия, которые ассистенту разрешено выполнять самостоятельно, настраиваются отдельно.

## Запуск сервера

Сервер рассчитан на Linux и .NET 10 SDK. Для локального распознавания и синтеза речи понадобятся Python и соответствующие модели. Совместимая видеокарта NVIDIA может ускорить обработку, но возможность запуска на CPU зависит от выбранной модели.

~~~bash
git clone https://github.com/iatethelogs/OpenAssistant.git
cd OpenAssistant/software/openassistant-server
dotnet run -c Release
~~~

Откройте **http://127.0.0.1:5055/setup.html** на компьютере с сервером. Мастер проведёт через установку языковой модели, распознавания, синтеза речи и подключение музыки. После настройки основные разделы доступны по адресу **http://127.0.0.1:5055/**.

Для подключения к веб-интерфейсу удалённого сервера используйте SSH-туннель:

~~~bash
ssh -L 5055:127.0.0.1:5055 user@server
~~~

Затем откройте **http://127.0.0.1:5055/** на своём компьютере. Административные API рассчитаны на локальный доступ; не публикуйте панель и ключи устройства в открытом интернете.

Подробности установки, настройки моделей и подключения клиентов — в [руководстве по серверу](software/openassistant-server/README.md).

## Подключение клиентов

OpenAssistant Server общается с клиентами по WebSocket. Клиент может отправить текст или запись микрофона, получить текст ответа, голосовой поток и команды воспроизведения музыки.

Для проверки без физической колонки есть [симулятор для Windows](software/openassistant-simulator/README.md). Он использует микрофон и динамики компьютера и позволяет проверить весь путь от запроса до голосового ответа.

Аппаратный прототип создаётся на **ESP32-P4**. Разработка прошивки и собственной платы ведётся отдельно от сервера; готовую колонку из репозитория пока собрать нельзя. Материалы по прототипу находятся в разделе [hardware](hardware/README.md).

## Музыкальные сервисы и умный дом

Сейчас можно подключить **Яндекс Музыку**, **интернет-радио** и **Home Assistant**. Музыка использует аккаунт пользователя и сетевое соединение; локальные языковые и речевые модели после загрузки весов не требуют облачного API.

В интерфейсе также представлены VK Музыка, Spotify, Apple Music, YouTube Music и локальная медиатека. Пока это обозначения будущих источников: подключение и воспроизведение через них не реализованы.

В планах также интеграция с **умным домом Яндекса**, поддержка локальной музыкальной библиотеки, общая очередь воспроизведения, мультирум и более гибкие правила управления устройствами. Эти функции ещё не входят в работающую версию сервера.

## Состояние разработки

Сервер и программные инструменты опубликованы и продолжают развиваться. Аппаратная часть, полноценный музыкальный плеер с несколькими источниками и прошивка законченной колонки ещё в работе.

Исходный код доступен в этом репозитории. У некоторых используемых моделей, музыкальных сервисов и наборов данных есть собственные условия использования.
