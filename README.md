# OpenAssistant

OpenAssistant — открытый проект голосового ассистента, который можно запустить на собственном сервере и подключить к нему колонку или другой клиент. Он объединяет распознавание речи, языковую модель, синтез голоса, музыкальные источники и управление умным домом.

**Мартин** — название одного из разрабатываемых вариантов колонки. Оно не привязано к платформе: устройства и имя ассистента могут быть другими.

Проект находится в разработке. Сервер и инструменты уже доступны в репозитории; самостоятельная аппаратная колонка пока не является готовым продуктом.

## Что работает

- **Разговор с ассистентом.** Локальные LLM через llama.cpp и OpenAI-совместимый API, потоковые ответы и вызовы инструментов. Поддерживается текстовый и голосовой диалог.
- **Память.** История разговоров сохраняется на сервере между сеансами. Можно выбирать профиль собеседника, обращаться к предыдущим диалогам и очищать память. Автоматического распознавания личности по голосу пока нет.
- **Распознавание речи.** GigaAM v3, запись с микрофона и проверка результата через веб-интерфейс.
- **Синтез речи.** Qwen3-TTS: готовые голоса CustomVoice и создание тембра по описанию через VoiceDesign. Доступны параметры генерации, включая фиксированный seed и строгий режим. Полная неизменность звучания моделью не гарантируется.
- **Home Assistant.** Подключение по API, чтение актуальных состояний и управление поддерживаемыми устройствами. Команды управления отключены по умолчанию. После отправки действия сервер повторно проверяет состояние и сообщает, если результат не подтверждён.
- **Музыка и радио.** Подключение аккаунта Яндекс Музыки, поиск и воспроизведение доступных треков, каталог интернет-радио.
- **Веб-панель.** Мастер настройки, установка и запуск моделей, назначение GPU, тесты речи, управление голосом, интеграции, устройства, события и журналы.

Доступность отдельных функций зависит от установленной модели, оборудования и подключённых сервисов.

## Как это устроено

OpenAssistant Server принимает аудио или текст от клиента, обрабатывает запрос и передаёт ответ обратно. Распознавание, LLM и синтез могут работать на одном Linux-сервере, в том числе с несколькими видеокартами NVIDIA.

Клиентом может быть физическая колонка, симулятор на Windows или веб-диалог. Один сервер рассчитан на подключение нескольких устройств.

Для умного дома используются проверяемые запросы к Home Assistant: сведения о текущем состоянии поступают из API, а не из предположений языковой модели. Память разговоров хранится отдельно по явно выбранным профилям. Исторические сведения не используются как источник текущих показаний датчиков.

## Начало работы

Для серверной части нужен Linux и **.NET 10 SDK**. Обработка речи и запуск локальных моделей требуют дополнительных зависимостей, которые настраиваются в мастере. Для ускорения поддерживаются совместимые GPU NVIDIA; часть задач может выполняться на CPU.

```bash
git clone https://github.com/iatethelogs/OpenAssistant.git
cd OpenAssistant/software/openassistant-server
dotnet run -c Release
```

Откройте веб-панель по адресу **http://127.0.0.1:5055/** на машине с сервером. Для первоначальной настройки перейдите на **/setup.html**. Сервер по умолчанию прослушивает порт 5055; для доступа с другого компьютера используйте защищённое соединение или SSH-туннель.

В мастере последовательно выбираются языковая модель, движок распознавания, голос и музыкальные подключения. Уже загруженные веса обнаруживаются повторно, если находятся в поддерживаемых каталогах или кешах.

Подробности: [OpenAssistant Server](software/openassistant-server/README.md).

## Музыка

Сейчас доступны **Яндекс Музыка** и **интернет-радио**. Для Яндекс Музыки пользователь подключает собственный аккаунт; доступность контента определяется условиями сервиса и аккаунта.

В планах:

- VK Музыка и Spotify;
- локальная библиотека с компьютера, сервера или NAS;
- другие музыкальные провайдеры;
- очередь воспроизведения, плейлисты и мультирум.

Эти источники и функции не следует считать уже реализованными.

## Умный дом

**Home Assistant** уже подключается через адрес сервера и долгоживущий токен. OpenAssistant получает список устройств и их состояния, а также позволяет разрешить управление освещением, выключателями, вентиляторами, шторами и медиаплеерами.

Для устройств с поддерживаемыми действиями сервер проверяет состояние до и после команды. Если состояние не удалось прочитать или подтвердить, ассистент сообщает об этом. Это не заменяет обратную связь от самого оборудования и не гарантирует физическое выполнение команды.

Интеграция с **умным домом Яндекса** запланирована отдельно: предполагается работа с уже добавленными в аккаунт устройствами и сценариями без переноса их в OpenAssistant.

## Колонки и аппаратная часть

Разрабатывается колонка на **ESP32-P4** с микрофонами, аудиотрактом, сенсорным управлением и светодиодной матрицей. Важные задачи аппаратной части — захват речи на расстоянии, подавление эха при воспроизведении и стабильная связь с сервером.

Репозиторий содержит прототипы и материалы по разработке, но пока не содержит законченного комплекта для сборки готовой колонки.
