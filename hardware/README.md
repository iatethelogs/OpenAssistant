# Hardware

Аппаратные материалы OpenAssistant.

## Прототип

Проверка слова активации выполняется на Waveshare ESP32-P4-WIFI6-DEV-KIT с ESP32-C6 в роли Wi-Fi-сопроцессора. Для записи и воспроизведения звука используются ES8311 и NS4150B.

| Сигнал | GPIO ESP32-P4 |
| --- | --- |
| I²C SDA / SCL | 7 / 8 |
| I²S MCLK / BCLK / WS | 13 / 12 / 10 |
| I²S DOUT / DIN | 9 / 11 |
| Управление усилителем | 53 |

Дальнейшие схемы, платы и материалы по сборке будут размещаться здесь.
