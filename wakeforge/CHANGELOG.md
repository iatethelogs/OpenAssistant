# История изменений

## 0.6.0

- Голосовой корпус Golos (OpenSLR114) стал обязательной частью скачивания и подготовки обучения.
- Добавлена потоковая обработка официального архива Golos: транскрипции проверяются, совпадения с целевым словом отбрасываются, реальная речь сохраняется отдельными отрицательными примерами.
- Подготовленные записи Golos используются и для аугментации, и как отдельные негативы. Источник Golos относится только к train, чтобы не смешивать неизвестных дикторов между выборками.
- SLR26 и SLR28 используются обязательно, даже в проектах со старым отключённым флагом.
- Мастер проверяет наличие обработанного Golos перед запуском генерации, подготовки признаков и обучения. Неуспешная загрузка не считается завершённой.
- Оценка дискового пространства учитывает большой архив Golos.
- README переписан с упором на реальный сценарий пользователя и ограничения alpha-версии.
