# WakeForge

**Обучите голосового ассистента реагировать на своё слово.**

WakeForge — инструмент из проекта [OpenAssistant](../README.md), полностью открытой умной колонки, работающей без интернета и облачных сервисов.

Например, вы хотите, чтобы колонка реагировала на имя «Мартин», но не путала его со словами «Марина», «Марти» или «Маша». WakeForge создаст примеры речи, подготовит звуковой датасет, обучит одну компактную нейросеть и сохранит готовую модель слова активации.

## Запуск

WakeForge рассчитан на Linux и Python 3.10–3.12. Для обучения рекомендуется видеокарта NVIDIA. Для обработки записей потребуется `ffmpeg`.

Откройте папку `wakeforge` и запустите:

```bash
python3 start.py
```

Появится интерактивный мастер, который проведёт через создание проекта, настройку слова активации, запись голоса, подготовку данных и обучение. Если процесс был прерван, его можно продолжить при следующем запуске.

## Как создаётся модель

Сначала вы выбираете слово активации и вводите похожие слова, которые не должны включать ассистента. Затем задаёте количество голосов и примеров. Программа покажет рекомендуемые значения и позволит выбрать свой объём.

Qwen3-TTS синтезирует нужные произношения разными голосами. Можно также выбрать микрофон, прочитать предложенные фрагменты и использовать записи собственного голоса для создания дополнительных примеров.

Whisper проверяет произношения. Затем WakeForge добавляет акустические условия реального мира: фоновую речь, шумы, эхо и изменения громкости. Из подготовленных записей извлекаются спектральные признаки, на которых обучается MicroWakeWord.

После обучения программа проверяет распознавание на отдельных примерах и сохраняет модель в формате **TFLite**. Её можно использовать в собственной колонке на ESP32 или другом устройстве с совместимой обработкой звука.

## Откуда берутся звуки

WakeForge автоматически загружает три обязательных набора данных:

- **Golos** — настоящая русская речь для отрицательных примеров и разговоров на фоне.
- **OpenSLR 26** — акустические характеристики помещений для имитации эха.
- **OpenSLR 28** — записи шумов и акустических эффектов.

Модели синтеза и распознавания речи загружаются при первом использовании. Для первоначальной подготовки требуется интернет и свободное место на диске, ориентировочно от 35–50 ГБ. Обученная модель слова активации работает локально и не требует подключения к сети.

## Что получается в результате

В каталоге проекта появляется файл `.tflite` — компактная модель, которая распознаёт выбранное слово в потоке звука. WakeForge создаёт именно детектор слова активации; остальные функции умной колонки разрабатываются в рамках OpenAssistant.
