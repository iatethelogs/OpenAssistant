# WakeForge

**Обучение собственного слова активации из консоли, без правки конфигурационных файлов.**

Автор: **iatethelogs**. Статус: **0.6.0 alpha**.

Вы вводите слово, например «Мартин», добавляете похожие отрицательные слова, выбираете количество голосов и записей. Программа генерирует примеры разными голосами, проверяет правильность произношения через Whisper, накладывает реальные шумы и чужую речь, обучает одну MicroWakeWord-модель и экспортирует TFLite.

В обычном режиме всё настраивается в пошаговом мастере. Никаких команд на каждый этап и ручного редактирования JSON.

## Запуск

Нужны Linux, Python 3.10–3.12, `ffmpeg`, интернет и достаточно места для корпуса речи. Желательна NVIDIA GPU.

```bash
sudo apt install ffmpeg
python3 start.py
```

При первом запуске программа предложит установить недостающие библиотеки в текущий Python (только после подтверждения). Docker и виртуальные окружения не используются.

## Откуда берутся данные

**SLR26, SLR28 и Golos обязательны.** Если любой из них отсутствует или не подготовлен, WakeForge не запускает обучение.

| Источник | Назначение |
| --- | --- |
| [SLR26](https://www.openslr.org/26/) | Импульсные характеристики помещений, эхо и реверберация |
| [SLR28](https://www.openslr.org/28/) | Реальные и синтетические шумы, реверберация |
| [Golos (SLR114)](https://www.openslr.org/114/) | Настоящая русская речь с транскрипциями для негативов и фоновых разговоров |

Golos занимает **около 18 ГБ при скачивании**. Архив кэшируется, загрузка может возобновляться после обрыва. Корпус не распаковывается целиком: из него извлекаются только необходимые аудиозаписи с подходящими транскрипциями.

Для первого большого проекта следует иметь **35–50 ГБ свободного места**, больше при расширенных объёмах. Также отдельно скачиваются веса Qwen3-TTS и Whisper.

В реальном корпусе Golos записи без текстовой расшифровки и записи с целевым словом отбрасываются. Golos используется только в обучающей выборке: не для всех записей можно надёжно определить диктора и безопасно разделить его между train/val/test.

## Голоса людей

Можно выбрать микрофон и записать несколько фрагментов собственной речи, прослушать дубль и перезаписать неудачную попытку. Эталон применяется локально в Qwen3-TTS Base для синтеза дополнительных примеров. Записывайте только свой голос или голос человека, согласившегося на клонирование.

## Результат

Мастер сохраняет данные по этапам и умеет продолжать после остановки. Готовый файл будет лежать в `projects/<слово>/models/` как `.tflite`.

Количество примеров не зависит от объёма видеопамяти. GPU влияет на размер batch, скорость генерации и обучения. Для ESP32 нужен совместимый потоковый MicroFrontend и корректная обработка звука микрофона.

## Тестирование и ограничения

Это **alpha**, а не проверенный стабильный релиз. Локальные тесты проверяют в том числе обработку искусственного архива Golos, но весь путь с загрузкой 18 ГБ официального корпуса и обучением на чистой GPU-машине пока не испытан.

Чтобы прогнать тесты:

```bash
python3 -m unittest discover -s tests -v
```

Код WakeForge распространяется по MIT. Корпуса, модели Qwen и чужие голосовые записи имеют свои лицензии, которые нужно соблюдать отдельно.

Исходники и история изменений будут размещаться в этом каталоге. Ошибки и предложения можно открывать в GitHub Issues.
