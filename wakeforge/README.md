# WakeForge

**Своё слово активации без ручной сборки десятка скриптов.**

Автор: **iatethelogs**. Лицензия кода: MIT. Текущая версия: **0.6.0 alpha**.

WakeForge — консольный мастер для обучения компактной модели, которая слышит определённое слово. Например, вы выбираете «Мартин», указываете похожие слова вроде «Марина» и «Маша», а программа подготавливает записи, обучает одну модель и сохраняет её в формате TFLite.

Это не готовый голосовой ассистент. WakeForge обучает только детектор слова активации. Всё работает на вашем компьютере: синтез, обработка звука и обучение не требуют передачи ваших записей в сервис WakeForge.

## Быстрый старт

Нужны **Linux, Python 3.10–3.12**, подключение к интернету, свободное место на диске и желательно NVIDIA GPU. Потребуется `ffmpeg` для декодирования реальной речи из Golos. CUDA-драйвер программа не устанавливает.

```bash
sudo apt install ffmpeg
python3 start.py
```

На первом запуске мастер предложит установить Python-библиотеки в текущую среду. Установка не происходит без подтверждения. Docker и виртуальные окружения не нужны. При необходимости зависимости можно установить отдельно.

Дальше программа проведёт вас через настройку без правки файлов: слово, похожие негативы, количество примеров, выбор GPU и CPU-воркеров, запись реального голоса с микрофона, загрузка данных, синтез, аугментации, обучение и проверка.

После остановки проект можно продолжить. Обучение рассчитано на одну выбранную GPU, генерация может использовать несколько. **Размер датасета не зависит от видеопамяти**, меняются только настройки выполнения.

## Что скачивает WakeForge

Три корпуса данных обязательны. Без них программа не отмечает загрузку успешной и не запускает обучение:

| Источник | Для чего нужен | Объём загрузки |
| --- | --- | --- |
| [OpenSLR 26](https://www.openslr.org/26/) | Импульсные характеристики виртуальных помещений: эхо и отражения | около 180 МБ |
| [OpenSLR 28](https://www.openslr.org/28/) | Реальные и синтетические акустические отклики, фоновые шумы | около 1,3 ГБ |
| [Golos, OpenSLR 114](https://www.openslr.org/114/) | Настоящая русская речь с текстовой расшифровкой | около 18 ГБ |

Модели Qwen3-TTS и Whisper также скачиваются при первом использовании. **Заранее подготовьте хотя бы 35–50 ГБ свободного места**, а для больших проектов больше: сохраняются и исходные файлы, и обработанные аудиозаписи, и спектральные признаки.

Golos скачивается целиком в сжатом виде **один раз**, с возобновлением прерванной загрузки. Программа не распаковывает весь корпус на диск. Она последовательно читает архив, выбирает необходимое количество записей, проверяет их транскрипции и конвертирует в 4-секундные FLAC-файлы для обучения.

Из Golos берутся только подтверждённые текстом фразы, в которых отсутствует целевое слово. Если транскрипция отсутствует, запись не используется. Подготовленные реальные записи применяются как **отрицательные примеры** и как фоновая речь для аугментаций. Голосовые идентификаторы Golos не всегда доступны, поэтому реальные записи Golos используются только для обучения, а независимые проверки остаются на других источниках.

Исходные архивы и веса не входят в Git-репозиторий. Лицензии Golos, OpenSLR и нейросетевых весов действуют независимо от MIT-лицензии WakeForge. Убедитесь, что планируемое использование данных разрешено их правообладателями.

## Что происходит во время обучения

Сначала Qwen3-TTS создаёт примеры нужного слова, похожих слов и обычных фраз разными синтетическими голосами. При желании можно записать несколько собственных фраз, выбрать микрофон и подключить клонирование голоса через Qwen3-TTS Base. Используйте только свои голоса или записи людей, согласившихся на это.

Затем Whisper отбрасывает неудачные произношения слова активации. К успешным записям добавляются фоновые разговоры из Golos, шумы SLR28 и эхо из SLR26/28. Положительные и отрицательные примеры преобразуются в спектральные признаки через MicroFrontend, после чего обучается одна модель MicroWakeWord.

В конце WakeForge проверяет её на отдельных наборах примеров и сохраняет TFLite-файл в `projects/<имя>/models/`. Для работы модели на ESP32 или компьютере необходим совместимый потоковый MicroFrontend и корректная обработка микрофона.

## Сколько примеров нужно

В мастере есть пробный, рекомендуемый и расширенный режимы. Программа показывает планируемое число TTS-генераций, аугментаций и итоговых файлов. Каждое значение можно изменить вручную, не открывая JSON. Большой датасет не гарантирует качество: важны разнообразие голосов, реальные отрицательные слова и проверка непрерывного звука.

## Состояние проекта

**Alpha.** Автоматизированные локальные тесты охватывают консольный мастер, форматы данных и обработку небольшого искусственного корпуса Golos. Полный запуск с загрузкой 18 ГБ Golos, Qwen3-TTS, TensorFlow на NVIDIA и экспортом TFLite на чистой системе пока не подтверждён. Если исходный архив Golos окажется иной структуры, программа остановится с диагностикой, а не заменит реальную речь синтетической незаметно для пользователя.

Тесты разработчика:

```bash
python3 -m unittest discover -s tests -v
```

Идеи, отчёты об ошибках и предложения по улучшению можно оставлять в GitHub Issues. Внутренние подкоманды `python3 -m wakeforge --help` доступны для автоматизации, но обычному пользователю достаточно `python3 start.py`.
