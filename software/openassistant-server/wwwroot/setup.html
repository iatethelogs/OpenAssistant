Шаг 03 / голос
Дайте Мартину
собственный голос.
Локальный синтез без облачного озвучивания. Сгенерируем тестовую фразу, прослушаем её и измерим скорость синтеза.


Модель синтеза
Компактная Qwen3-TTS 0.6B. Для первого запуска используется набор готовых голосов.
Голос по описанию доступен в VoiceDesign 1.7B. Эта модель тяжелее: при нехватке VRAM будет предпринята попытка запуска на CPU.


Система сама установит адаптер и загрузит веса модели.
