Настройка Windows Simulator и будущей ESP32-P4. Состояние WebSocket-соединений обновляется автоматически.

Параметры устройства

ws://SERVER_IP:5055/ws
Существующий ключ не раскрывается. При генерации старый ключ заменяется.

Ключ понадобится в поле «Ключ устройства» Windows-эмулятора. Создание нового ключа требует повторного подключения старых клиентов.
