УСТРОЙСТВА

Подключение устройства

Устройства добавляются отдельно, после настройки OpenAssistant. Никакая колонка, включая «Мартин», не создаётся автоматически.

Подключить новую колонку

Адрес WebSocket и ключ доступа

ws://SERVER_IP:5055/ws
Не создан в этой сессии

Сейчас используется общий ключ подключений сервера. Его перевыпуск делает старый ключ недействительным для новых подключений. Отдельные имена и профили устройств — следующий этап разработки.
