Piper использует CPU и готовые русские голоса. Для Qwen доступны отдельные варианты Faster и VoiceDesign. В режиме качества длинный ответ может делиться на части из-за ограничения модели.

Голос и повторяемость синтеза

Профиль используется и мастером, и обычными ответами ассистента

Режим с фиксированным seed повторяет случайный выбор токенов. Строгий режим отключает sampling; он может звучать менее естественно. Изменение параметров не требует перезагрузки модели.
