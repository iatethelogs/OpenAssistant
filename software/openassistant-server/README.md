# OpenAssistant Server

OpenAssistant Server — локальный сервер голосового ассистента на C# и .NET 10. Он объединяет распознавание речи, языковую модель, синтез голоса и подключаемые сервисы.

Сервер принимает звук от совместимых устройств, преобразует речь в текст, обрабатывает запрос локальной языковой моделью и передаёт звуковой ответ обратно. Генерация текста и синтез речи выполняются по частям, поэтому воспроизведение начинается до завершения всего ответа.

## Возможности

- Распознавание русской речи с помощью whisper.cpp.
- Подключение локальных языковых моделей через OpenAI-совместимый API, в том числе llama.cpp.
- Синтез речи через Piper с выбором голосовой модели.
- Двусторонняя передача звука и команд по WebSocket.
- Независимые диалоги для подключённых устройств и прерывание ответа.
- Подключаемые инструменты для взаимодействия с внешними системами.
- Доступ к состояниям устройств и вызовам сервисов Home Assistant.
- Каталог интернет-радиостанций.

## Установка

Необходимы .NET SDK 10, llama-server, whisper.cpp и Piper. Укажите адрес языковой модели, исполняемые файлы речевых движков и пути к их моделям в `appsettings.json`.

Для запуска:

```bash
cd software/openassistant-server
dotnet run
```

Проверить работу сервера можно по адресу `http://127.0.0.1:5055/health`.

## Подключение устройств

Устройства подключаются к `/ws` по WebSocket. Входной звук передаётся в формате PCM16 LE, моно, 16 кГц. Завершение записи обозначается сообщением `{"type":"end"}`. Для передачи текстового запроса предусмотрено `{"type":"text","text":"привет"}`, для остановки ответа — `{"type":"cancel"}`.

В ответ сервер отправляет события распознанного текста, генерации ответа и воспроизведения звука. Выходной поток содержит PCM16 LE, моно. Частота дискретизации задаётся параметром `OutputSampleRate`.

## Настройки

Основные параметры находятся в секции `OpenAssistant` файла `appsettings.json`. Их можно переопределять переменными окружения с префиксом `OpenAssistant__`.

Для Home Assistant укажите `HomeAssistantUrl` и `HomeAssistantToken`. Токены и другие секреты рекомендуется передавать через переменные окружения.

Сервер по умолчанию доступен только на локальном интерфейсе. При открытии сетевого доступа необходимо настроить аутентификацию и ограничить доступ к управляющим командам.
