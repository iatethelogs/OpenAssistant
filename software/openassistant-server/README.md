# OpenAssistant Server

OpenAssistant Server — локальный сервер голосового ассистента для Linux на C# и .NET 10. Принимает речь с подключённых устройств, обращается к языковой модели, синтезирует голосовой ответ и передаёт звук обратно по WebSocket.

## Возможности

- Локальные языковые модели с OpenAI-совместимым API.
- Русскоязычное распознавание речи GigaAM.
- Синтез речи Qwen3-TTS с выбором голоса.
- Настраиваемые профили запуска LLM, STT и TTS, включая выбор одной или нескольких NVIDIA GPU.
- Передача текста ответа по мере генерации, озвучивание по фразам и прерывание ответа.
- Веб-интерфейс диалога и отдельная панель управления моделями и интеграциями.
- Управление устройствами Home Assistant через локальный API.
- Поиск интернет-радиостанций в каталоге Radio Browser и прослушивание в браузере.
- Подключение аккаунта Яндекс Музыки по OAuth-токену и поиск композиций в каталоге.

## Требования

Linux, .NET SDK 10 и NVIDIA Driver с утилитой `nvidia-smi` для просмотра доступных видеокарт. Для работы нейросетей потребуются установленные движки с поддержкой GPU и соответствующие модели.

Распознавание речи подключается по HTTP через `POST /v1/audio/transcriptions`. Синтез Qwen3-TTS подключается через `POST /synthesize` с ответом WAV PCM16 mono. GigaAM и Qwen3-TTS выполняются внешними GPU-движками; OpenAssistant управляет их процессами и отправляет запросы, но не содержит их нейросетевых runtime.

## Запуск

```bash
cd software/openassistant-server
dotnet run
```

После запуска в терминале появится логотип OpenAssistant и адреса веб-интерфейсов.

- **Диалог:** `http://127.0.0.1:5055/`
- **Настройки:** `http://127.0.0.1:5055/settings.html`
- **Модели и музыка:** `http://127.0.0.1:5055/media.html`

## Выбор моделей и GPU

На странице «Модели и музыка» отображается список NVIDIA GPU, определённых через `nvidia-smi`. Для каждого движка настраивается отдельный профиль: абсолютный путь к исполняемому файлу Linux, рабочая папка, аргументы запуска и номера GPU. Затем модель можно запустить и остановить из браузера.

Для ограничения GPU применяется переменная `CUDA_VISIBLE_DEVICES`. Индексы видеокарт внутри процесса могут отличаться от системных. После запуска необходимо указать адрес работающего сервиса на странице «Настройки».

Сервер управляет только процессами, запущенными через собственную панель. Внешние процессы он не завершает.

## Музыка

Для поиска радио используется открытый каталог Radio Browser. Найденные аудиопотоки можно воспроизвести непосредственно в браузере, если поддерживается формат станции.

Для подключения Яндекс Музыки введите OAuth-токен собственного аккаунта. После подключения доступен поиск треков в каталоге. Используется неофициальный API, поэтому доступность функций зависит от сервиса. Воспроизведение треков Яндекс Музыки и управление музыкальной очередью пока не реализованы.

## Подключение голосовых устройств

WebSocket-адрес: `/ws`. Входной звук: PCM16 LE mono, 16 кГц. Сообщение `{"type":"end"}` завершает аудиозапрос; `{"type":"text","text":"привет"}` отправляет текст; `{"type":"cancel"}` прерывает ответ. Выходной звук: PCM16 LE mono с частотой, заданной в настройках синтеза.

## Безопасность и хранение данных

Конфигурация сохраняется в локальных JSON-файлах и не требует базы данных. Файлы с токенами и локальными настройками исключены из Git. Панели управления и API настроек доступны только с локального адреса; они не предназначены для публикации в интернет без дополнительной аутентификации и обратного прокси.
