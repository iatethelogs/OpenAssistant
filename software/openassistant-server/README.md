# OpenAssistant Server

Локальный сервер голосового ассистента с распознаванием русской речи, синтезом голоса, диалоговой моделью и подключением устройств умного дома.

## Возможности

- Распознавание речи с помощью GigaAM v3 с GPU-ускорением.
- Подключение локальной языковой модели через OpenAI-совместимый API.
- Синтез речи с помощью Qwen3-TTS с выбором голоса.
- Потоковая передача текста ответа и звука по WebSocket.
- Независимые сессии устройств и прерывание голосового ответа.
- Управление Home Assistant и список пользовательских интернет-радиостанций.
- Веб-страница для проверки текстовых запросов и настройки голоса.

## Запуск

Установите .NET SDK 10 и запустите локальные сервисы языковой модели, GigaAM и Qwen3-TTS на GPU. Для GigaAM используется HTTP endpoint `POST /v1/audio/transcriptions` в формате OpenAI Audio Transcriptions. Для Qwen3-TTS необходим локальный HTTP-адаптер с `POST /synthesize`: на входе JSON с полями `text`, `model`, `voice`, `language`, `sample_rate`, на выходе WAV PCM16 mono с указанной частотой. Сами нейросетевые runtime и адаптер Qwen3-TTS в состав сервера не входят.

Адреса сервисов и параметры моделей можно изменить через веб-панель настроек. Сохранённые значения применяются без перезапуска для новых запросов.

```bash
cd software/openassistant-server
dotnet run
```

После запуска сервер показывает в консоли логотип и адреса интерфейсов.

- `http://127.0.0.1:5055/` — диалог с ассистентом.
- `http://127.0.0.1:5055/settings.html` — настройка моделей, голосов, Home Assistant и интернет-радио.

Проверка состояния: `/health`. Панель настроек работает только при локальном подключении.

## Подключение колонки

WebSocket: `/ws`. Входной поток: PCM16 LE mono, 16 кГц. Выходной поток: PCM16 LE mono, частота определяется `OutputSampleRate`. Конец фразы: `{"type":"end"}`; текстовый запрос: `{"type":"text","text":"привет"}`; остановка: `{"type":"cancel"}`.

Настройки Home Assistant, включая токен, вводятся в панели управления. Конфигурация сохраняется локально в `settings.local.json`, который исключён из Git.

При включении доступа по локальной сети используйте доверенную сеть: публичная авторизация для WebSocket и инструментов пока не предусмотрена.
