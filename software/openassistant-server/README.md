# OpenAssistant Server

Серверная часть [OpenAssistant](../../README.md). Запускает речевые и языковые модели, обрабатывает запросы клиентов, хранит историю диалогов и связывает ассистента с внешними сервисами.

## Запуск

Нужен Linux и .NET 10 SDK.

```bash
cd software/openassistant-server
dotnet run -c Release
```

Веб-панель: **http://127.0.0.1:5055/**. Мастер настройки: **http://127.0.0.1:5055/setup.html**.

Для доступа через SSH с другого компьютера:

```bash
ssh -p <SSH_PORT> -L 5055:127.0.0.1:5055 user@server
```

После подключения откройте `http://127.0.0.1:5055/` на своём компьютере.

## Настройка

Мастер последовательно подготавливает LLM, распознавание речи, синтез голоса и подключение музыки.

**Языковая модель.** Можно выбрать модель из каталога или указать собственный GGUF на Hugging Face. Доступны назначение видеокарты, контекст, параметры генерации и проверка скорости ответа. Установка и загрузка весов отображаются с прогрессом; уже скачанные файлы могут использоваться повторно.

**Распознавание.** GigaAM v3. В мастере и диагностике можно записать пять секунд звука, прослушать запись, получить распознанный текст и посмотреть задержку обработки.

**Синтез речи.** Qwen3-TTS CustomVoice с готовыми голосами и VoiceDesign с описанием тембра. Профиль голоса содержит выбор режима генерации, seed, temperature, top-p, top-k и штраф за повторения. Это позволяет уменьшить вариативность звучания, но не гарантирует идентичный голос в любых условиях.

**Музыка.** Подключение Яндекс Музыки через аккаунт пользователя. Интернет-радио доступно отдельно в разделе музыки.

Модели управляются независимо: запуск, остановка, профили и выбор GPU находятся в разделе «Модели».

## Диалоги и память

Клиенты общаются с сервером через WebSocket `/ws`. Поддерживаются текстовые команды и потоковое аудио PCM16, 16 кГц, mono. Ответ возвращается текстом и аудиофрагментами.

История разговоров сохраняется на сервере между подключениями. У каждого выбранного профиля отдельная память. При ответе учитываются последние реплики и релевантные фрагменты прежних разговоров. Профиль выбирается в разделе «Диалог» или командой WebSocket:

```json
{"type":"profile","name":"Общий"}
```

Это ручное назначение профиля, а не биометрическое распознавание говорящего. Историю можно удалить из интерфейса. Файлы памяти находятся в `conversation-memory.local/` и не включаются в Git.

## Home Assistant

Подключение выполняется в разделе «Интеграции» по адресу Home Assistant и долгоживущему токену. После подключения доступны просмотр устройств, их фактических состояний и агентные инструменты.

Для вопросов о текущем состоянии поддерживаемых устройств сервер получает данные из Home Assistant. При управлении выполняется проверка устройства, вызов разрешённой команды и повторное чтение состояния. **HTTP-ответ сам по себе не считается доказательством выполнения действия.** Если ожидаемое состояние не подтверждено, ассистент не сообщает об успехе.

Управление устройствами выключено по умолчанию. Разрешение на изменение состояний включается отдельно в настройках инструментов. Поддерживаются ограниченные команды для освещения, выключателей, вентиляторов, штор и медиаплееров. Это экспериментальная интеграция: сложные сценарии и автоматизации пока не охвачены.

## Веб-панель

- **Обзор:** состояния сервисов, GPU, память, диски и подключённые устройства.
- **Модели:** скачивание, запуск, остановка и профили LLM/STT/TTS.
- **Диагностика:** проверка LLM, записи, распознавания и синтеза.
- **Настройки:** системная инструкция и параметры голосового ассистента.
- **Диалог:** веб-чат, выбор профиля собеседника и управление памятью.
- **Интеграции:** Home Assistant, Яндекс Музыка и разрешения инструментов.
- **Музыка:** доступные музыкальные источники и интернет-радио.
- **Устройства, события, журнал:** подключение клиентов и диагностика.

Интерфейс использует короткие переходы и не требует отдельного фронтенд-сервера.

## Подключение клиентов

В разделе «Устройства» отображаются адрес WebSocket, ключ доступа и активные подключения. Для тестирования без колонки можно использовать [OpenAssistant Simulator](../openassistant-simulator/README.md) на Windows.

Сервер поддерживает потоковые ответы и инструменты для музыки, радио и Home Assistant. Внешний музыкальный поток клиент получает непосредственно по предоставленному URL.

## Доступ и данные

Административные API рассчитаны на локальное обращение. Не публикуйте панель управления в интернет без собственной аутентификации и защищённого прокси. Токены сервисов, настройки и история разговоров хранятся локально; эти файлы исключены из репозитория.

Зависимости Python и совместимость GPU зависят от выбранных речевых движков. Для NVIDIA может потребоваться установленный CUDA Toolkit и совместимый PyTorch. Автоматическая настройка не заменяет драйвер видеокарты.

Сервер продолжает разрабатываться. Для новых комбинаций оборудования и моделей требуется проверка запуска и качества речи на целевой машине.
