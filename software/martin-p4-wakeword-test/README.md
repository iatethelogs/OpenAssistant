# Martin P4 Wake-word Test

Тест распознавания слова «Мартин» непосредственно на Waveshare ESP32-P4-WIFI6-DEV-KIT. Для локального вывода отладочной информации используются веб-интерфейс, осциллограмма и спектрограмма.

Проект разрабатывается на ESP-IDF 6.1 в CLion. В тестовой конфигурации используется аудиокодек ES8311, динамик через NS4150B, MicroFrontend и модель TensorFlow Lite Micro.

Текущая рабочая версия прошивки пока находится в локальном проекте CLion. Её исходники и модель должны быть перенесены сюда вместе, чтобы не опубликовать устаревшую версию диагностической прошивки вместо теста wake-word.
