# OpenAssistant Simulator

Windows-приложение для проверки взаимодействия с OpenAssistant Server без физической колонки.

Эмулятор записывает звук с микрофона, отправляет PCM16 mono 16 кГц на сервер по WebSocket, показывает распознанные фразы и текст ответа, воспроизводит голосовой PCM-поток и может самостоятельно открыть ссылку на музыкальный поток.

## Запуск

Установите .NET SDK 10 на Windows.

```powershell
cd software/openassistant-simulator
dotnet run
```

Укажите WebSocket-адрес сервера и нажмите «Подключиться». Для ручной записи нажмите «Говорить», а после произнесения запроса — «Закончить фразу». Можно отправить текст без микрофона.

## Кодовое слово

В разделе активации задаётся исполняемый файл локального детектора и его аргументы. Детектор получает PCM16 mono 16 кГц через stdin и должен выводить в stdout построчные JSON-события, например `{"type":"wake","word":"мартин","score":0.92}`. После такого события эмулятор начинает передавать голосовой запрос.

Модель WakeForge экспортируется в TFLite. Для её запуска необходим совместимый детектор с тем же аудиофронтендом, который использовался при обучении; TFLite-движок не включён в эмулятор.

## Протокол

Бинарные сообщения на сервер содержат PCM16 mono 16 кГц. Управление: `{"type":"end"}`, `{"type":"cancel"}`, `{"type":"text","text":"..."}`. События `transcript`, `text`, `audio_start`, `audio_end` показываются в приложении. Команда `play_media` с полями `url`, `title`, `source` запускает воспроизведение непосредственно на Windows-устройстве, без ретрансляции музыки через сервер.

Для воспроизведения ссылок используется Windows Media Foundation; поддержка формата зависит от установленных системных декодеров.
