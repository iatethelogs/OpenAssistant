# OpenAssistant Simulator

Windows-клиент OpenAssistant — эмулятор собственной умной колонки с RGB-матрицей, микрофоном, динамиками и подключением к серверу по WebSocket.

## Возможности

- Локальное распознавание слова активации через **C# и TensorFlow Lite**. Модель WakeForge `.tflite` загружается непосредственно в процесс; Rust, Python и внешние исполняемые файлы не нужны.
- Кнопка **«Имитировать wake-word»** — запускает тот же сценарий, что и срабатывание детектора.
- Буфер до начала речи, автоматическое завершение фразы по паузе, ручная запись, текстовый запрос и отмена.
- Серверные STT, LLM и TTS; потоковая передача PCM16 и воспроизведение голосового ответа без потери хвоста длинного аудио при быстрой передаче.
- Повторное wake-word во время ответа прерывает текущую речь и запускает запись следующего запроса. При воспроизведении из собственного динамика надёжность wake-word зависит от системного акустического эхоподавления.
- Прямой клиентский музыкальный плеер (MP3/AAC и потоки, которые умеет декодировать Windows).
- Запрос системной обработки микрофона Windows Communications и дополнительный программный шумофильтр. Музыка ставится на паузу на время ответа и возобновляется после него. Системное акустическое эхоподавление зависит от аудиодрайвера.
- Встроенный RGB-дисплей; при подключении получает размер матрицы, яркость, частоту обновления и анимации состояний от сервера. Размер по умолчанию — **32×10**. Поддерживаются пресеты и локальные RGB888-анимации.
- Профили собеседников и сохранение настроек клиента (кроме токена устройства).

## Запуск в Visual Studio

Откройте `OpenAssistant.Simulator.csproj` в Visual Studio с .NET 10 SDK и выберите **F5**. Сборка целиком выполняется Visual Studio, дополнительный скрипт не нужен.

В окне укажите `ws://IP_СЕРВЕРА:5055/ws`, ключ из панели сервера и выберите модель WakeForge `.tflite` либо её локальную `.json`-конфигурацию. Для тестирования без модели нажмите «Имитировать wake-word».

Текущая реализация аудиофронтенда MicroWakeWord использует независимые вычисления спектра на C#. Она воспроизводит порядок обработки (оконная функция, FFT, фильтробанк, шумоподавление, PCAN, логарифм, INT8), но является приближением фиксированной арифметики TFLite Micro. Порог чувствительности следует проверить на своих записях, прежде чем считать точность сопоставимой с ESP32.

## Матрица

Сервер: **Настройки → Дисплей** или **Мастер настройки → Дисплей**. Размер и число RGB-пикселей можно менять. Пресеты назначаются отдельно для состояний: отключено, ожидание, слушает, думает, отвечает, музыка и ошибка.

При подключении клиент получает `display_config` и события `display_state` через существующий WebSocket. В окне клиента есть кнопка «Обновить настройки». Для импорта локальной анимации поддерживается поток RGB888 из редактора: по `ширина × высота × 3` байт на кадр.

Анимации выполняются в самом клиенте. Сервер не передаёт 25 полноцветных кадров в секунду, поэтому не создаёт дополнительного сетевого трафика.
