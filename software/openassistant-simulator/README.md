# OpenAssistant Simulator

Эмулятор умной колонки для Windows. Использует микрофон и динамики компьютера, подключается к OpenAssistant Server и показывает виртуальную **RGB-матрицу 32 × 10**.

Симулятор работает по тому же WebSocket-протоколу, что и будущая физическая колонка: распознаёт слово активации на устройстве, отправляет речь на сервер, воспроизводит ответы и музыкальные потоки.

## Функции

- Захват PCM16 mono 16 кГц и локальный детектор WakeForge MicroWakeWord (.tflite или конфигурация .json).
- Секунда звука перед активацией, определение конца фразы по паузе, ручное управление записью.
- Прямая передача речи на сервер и отображение текста распознавания и ответа.
- Воспроизведение синтезированной речи и музыки через динамики Windows; MP3/AAC декодируются Media Foundation.
- Windows Communications audio processing: запрос AEC/NS/AGC у операционной системы. При отсутствии подходящего устройства переключение на обычный захват; дополнительно применяется программный high-pass и адаптивное шумоподавление.
- Музыка ставится на паузу на время голосовой команды и возобновляется после ответа. Активация поверх музыки включается отдельно.
- RGB-эмуляция матрицы 32×10, режимы ожидания, прослушивания, обработки, ответа и музыки. Поддерживается воспроизведение экспортированных файлов RGB888 (960 байт на кадр).
- Профиль памяти собеседника, сохраняемые настройки подключения и детектора; токен устройства на диске не сохраняется.

## Сборка и запуск

Требуется Windows 10/11 и **.NET 10 SDK**. Для локального распознавания WakeForge потребуется **Rust (MSVC toolchain)**, установленный через https://rustup.rs/, а также инструменты сборки C++ для Windows.

Откройте PowerShell в каталоге `software/openassistant-simulator`:

```powershell
.\build.ps1
dotnet run -c Release
```

При первоначальной сборке загружаются пакеты NuGet, Rust crate micro-wakeword и совместимый TensorFlow Lite runtime. Детектор собирается в `WakeDetector\target\release\openassistant-wake.exe` и автоматически копируется рядом с клиентом.

Если пока нужно только вручную отправлять речь без модели wake word:

```powershell
.\build.ps1 -WithoutWake
dotnet run -c Release
```

## Подключение

Укажите адрес `ws://IP_СЕРВЕРА:5055/ws` и **ключ устройства** из раздела «Устройства» веб-панели OpenAssistant. Для удалённой сети используйте `wss://`. Затем выберите профиль и нажмите «Подключиться».

При работе с WakeForge выберите файл `.tflite`, укажите имя слова и порог (начальное значение `0.87`). Детектор запускается автоматически при подключении. Вместо модели можно указать собственный внешний exe-детектор, принимающий поток PCM16 stdin и выводящий JSON-события в stdout.

Нажмите «Говорить» для ручной записи, «Завершить фразу» для отправки или произнесите слово активации. Сразу после слова записывается голос, сервер выполняет распознавание, обработку и синтез.

## Аудио и эхо

Windows Communications запрашивает системные эффекты AEC, шумоподавления и регулировки уровня. **Фактическая работа AEC зависит от микрофона, драйвера и установленного Windows APO**, поэтому режим захвата показывается отдельно. Программный фильтр удаляет низкочастотные помехи и снижает стационарный фоновый шум, но не заменяет полноценный адаптивный AEC.

Собственный голосовой ответ не используется как команда активации. Музыка автоматически приостанавливается после обнаружения wake word или ручного начала разговора. Вызов слова поверх играющей музыки отключён по умолчанию; включайте его на устройствах, где системный AEC действительно эффективен.

## Дисплей

Модуль `Display/RgbMatrixView.cs` отображает 320 физических RGB-диодов с точным соответствием координат. Внутренний кадр — RGB888, 32 пикселя в строке и 10 строк сверху вниз. Поддерживаются прямой порядок и serpentine для будущей прошивки.

В режиме ожидания можно загрузить экспортированную анимацию `.rgb` из редактора матрицы, установив в редакторе размер 32×10. Для других состояний показываются встроенные анимации. Скорость обновления экрана — около 15 кадров/с.

Клиент не требует Python, Docker или виртуального окружения. В исходном коде wake-детектора используется Rust; обучение модели выполняется отдельно в WakeForge.
