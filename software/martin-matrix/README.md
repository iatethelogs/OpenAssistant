# Martin Matrix Simulator

Настольный симулятор монохромного светодиодного дисплея Мартина.

Загружает GIF, APNG, WebP и SVG, переводит кадры в градации серого, масштабирует до заданного разрешения с антиалиасингом и показывает анимацию на виртуальной LED-матрице. Поддерживаются FPS, яркость, гамма, плавное смешивание кадров, предпросмотр стыка цилиндра и экспорт RGB888 с JSON или GIF.

## Запуск

```powershell
pip install -r requirements.txt
python martin_matrix.py
```

Для каждого пикселя экспортируемого RGB888 выполняется R = G = B.
